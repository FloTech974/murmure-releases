# Murmure : installeurs

Dictée vocale locale pour Windows : maintenir **Alt Gr**, parler, relâcher, et le texte s'écrit
dans l'application active. Tout est transcrit sur ton PC, rien n'est envoyé sur Internet.

Ce dépôt ne contient que les **installeurs** publiés (onglet *Releases*). Murmure s'en sert pour
ses mises à jour : *Options → Mises à jour → Rechercher une mise à jour*.

Chaque version contient :
- `Murmure-Setup-X.Y.Z.exe` : l'installeur (Windows 10/11, sans droits administrateur) ;
- `Murmure-Setup-X.Y.Z.exe.sha256` : son empreinte. Murmure refuse d'installer un fichier qui ne lui correspond pas.
